# OpenHealth Roadmap

## Actors

### Patient

- Manage medical history
- View timeline
- Manage allergies
- View AI summary
- Manage digital will
- Forgot Password (Email/Phone OTP)

### Doctor

- Search patient
- OTP-based access
- View medical timeline
- Add prescriptions
- Add remarks

### Lab

- Upload reports directly
- Link reports to patient timeline

## Security Rules

- Doctors cannot access digital will.
- Labs cannot access digital will.
- Timeline access requires patient consent.
- OTP required before doctor access.
- Password reset requires OTP verification.
- OTP expires after a limited time.
- OTP can only be used once.
